
# 灵墟：一念成仙

一个无需安装依赖的俯视角像素修仙动作肉鸽原型。使用浏览器打开 `index.html` 即可开始游戏。

## 操作

- 使用 `WASD` 或方向键移动；靠近妖物后会自动锁定并按节奏发射法术，无需手动瞄准或射击。
- 选择青霄剑修、天雷符师或丹霞药师；按 `E` 施展各自神通，左上角及按钮会显示技能冷却。
- 按 `Shift` 朝移动方向闪避（没有移动输入时朝锁定方向闪避），冷却状态显示在左上角身法槽。
- 每间石室有三波追击妖物，远程妖物会发射弹幕；躲避并击败它们推进波次。
- 触屏设备使用左侧方向键移动，并点按“施展神通”或“闪避”；自动攻击持续运作。
- 靠近灵气或疗伤掉落即可拾取；灵气积累到阈值后选择突破能力。
- 肃清三波后选择一项战利品强化，点击“进入下一间”继续探索。
- 使用 `Esc` 或右上角按钮暂停。

## 开发参考

- [aleksejspopovs/dungeons](https://github.com/aleksejspopovs/dungeons)：MIT 许可的 HTML5 Canvas 俯视角肉鸽示例，可参考其轻量画布游戏组织方式。
- [PixelLab-MCP](https://github.com/flynnsbit/PixelLab-MCP)：AI 像素角色、动画与地形生成工具候选；本原型未集成，采用前请核对其许可、数据处理方式及生成素材的使用权。

## Godot 4 迁移版

根目录的浏览器版本保留不变；Godot MVP 位于 `godot/`，不依赖外部素材。

1. 安装 Godot 4.x。
2. 在 Godot Project Manager 选择 **Import**，打开本仓库中的 `godot/project.godot`。
3. 按 **F6** 运行主场景，或按 **F5** 运行项目。

- 使用 `WASD` 或方向键移动；修士会自动锁敌并攻击。
- 按 `E` 或点击神通按钮施法；选择青霄剑修、天雷符师或丹霞药师以使用不同神通。
- 按 `Shift` 或点击身法闪避；闪避期间短暂无敌。
- 清除逐关增加的妖物波次可获得灵石；清关后可消耗灵石淬炼法器或提升气血，再进入下一关。
- 气血归零后可重新开始。游戏画面使用 GDScript 绘制的像素风占位图形。

当前开发环境未安装 Godot，尚未执行引擎解析或游戏内测；请在 Godot 4 编辑器导入项目并按 F5 启动验证。
