
# 灵墟：一念成仙

一个无需安装依赖的俯视角像素修仙动作肉鸽原型。使用浏览器打开 `index.html` 即可开始游戏。

## 操作

- 使用 `WASD` 或方向键移动；鼠标移动瞄准，按住鼠标左键或空格发射法术；按 `Shift` 朝移动方向闪避（无移动输入时朝瞄准方向），冷却期间看左上角身法槽。
- 每间石室有三波追击妖物，远程妖物会发射弹幕；躲避并击败它们推进波次。
- 触屏设备使用左侧方向键移动、右侧方向键瞄准，并按住“按住发射”施法；点按“闪避”即可快速位移。
- 靠近灵气或疗伤掉落即可拾取；灵气积累到阈值后选择突破能力。
- 肃清三波后选择一项战利品强化，点击“进入下一间”继续探索。
- 使用 `Esc` 或右上角按钮暂停。
